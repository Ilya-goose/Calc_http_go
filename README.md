# Calc_http_go
Сервис подсчёта арифметических выражений

Привет!
Я никогда не писал файл ридми, поэтому извини, что это выглядит ужасно, но я по-другому не умею.

Итак, я написал сервис для подсчёта арифметических выражений, с помощью которого ты можешь посчитать любой пример (ну почти))
В чем суть: ты запускаешь http-сервер, на который можешь отправлять запросы с записанными в них математическими выражениями. Здесь стоит сказать, что у меня довольно паршивый калькулятор, который не в состоянии посчитать некоторые сложное примеры (например, с множеством скобок), однако кое-что он всё-таки умеет.

Чтобы начать работу, нужно склонировать этот репозиторий к себе. Далее необходимо в терминале ввести команду "cd Calc_http_go", чтобы перейти в корневую папку проекта. Чтобы запустить сервер, нужно ввести команду 
"go run .\cmd\main.go". Теперь на сервер можно отправлять запросы. Это можно делать через командную строку с помощью curl, передавая в тело запроса необходимое выражение, а проще скачать удобное приложение Postman, которое позволит легко отправлять запрос на указанный адрес:
![image](https://github.com/user-attachments/assets/b4e3c476-73cf-4cf2-8a4c-f7c9d6afdec9)

Если вы желаете отправить curl запрос:

У сервиса 1 endpoint с url-ом /api/v1/calculate. Пользователь отправляет на этот url POST-запрос с телом: 
{"expression": "выражение, которое ввёл пользователь"}
В ответ пользователь получает HTTP-ответ с телом: 
{"result": "результат выражения"} 
и кодом 200, если выражение вычислено успешно, либо HTTP-ответ с телом: 
{ "error": "expression is not valid"}
и кодом 422, если входные данные не соответствуют требованиям приложения — например, кроме цифр и разрешённых операций пользователь ввёл символ английского алфавита. 
Ещё один вариант HTTP-ответа:
{"error": "internal server error"}
и код 500 в случае какой-либо иной ошибки («Что-то пошло не так»).


Примеры для проверки сервиса:
curl --location 'localhost:8080/api/v1/calculate' \
--header 'Content-Type: application/json' \
--data '{
  "expression": "2+2*2"
}'
Выведет {"result":6} и статус 200 (если в Postman)

curl --location 'localhost:8080/api/v1/calculate' \
--header 'Content-Type: application/json' \
--data '{
  "expression": "(2+2*2"
}'
Выведет {"error":"unbalanced brackets"} и статус 422

curl --location 'localhost:8080/api/v1/calculate' \
--header 'Content-Type: application/json' \
--data ''

Выведет {"error":"internal server error"} и статус 500.

Можно также проверить работу внутренних файлов с помощью тестов: application_test.go и calculation_test.go.
Для этого соответственно надо ввести в терминале команды go test ./internal/application/application_test.go или go test ./pkg/calculation/calculation_test.go
